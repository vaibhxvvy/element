# Code of Conduct

## Our Pledge

We want Element to be a welcoming project for anyone who wants to use it, report a bug,
or contribute code — regardless of experience level, background, or how they found it.

## Expected Behavior

- Be respectful in issues, PRs, and discussions.
- Assume good faith — most bug reports and "why is this like this" questions are genuine,
  not hostile.
- Give constructive feedback on code, not people.
- Accept that maintainer time is limited; a slow response isn't a dismissal.

## Unacceptable Behavior

- Harassment, insults, or personal attacks in any project space.
- Publishing others' private information without consent.
- Sustained disruption of issues, PRs, or discussions.

## Scope

This applies to all project spaces — GitHub issues, PRs, discussions, and any official
community channels (e.g. Discord, if/when one exists).

## Enforcement

Violations can be reported by opening a private message to the maintainer (see repository
profile for contact) or via GitHub's report tools. Maintainers may remove comments, close
threads, or ban repeat offenders at their discretion.
